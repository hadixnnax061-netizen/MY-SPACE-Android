MY SPACE v16.1 — Google Gemini · Paste Key Setup
============================

ما الجديد؟
- محادثة فعلية مع Gemini 3.8 Flash، وليست ردوداً ثابتة.
- وضعان مستقلان: التحدث مع النجم أو التحدث مع الكوكب.
- لكل شخصية محادثة محفوظة بشكل مستقل لكل نجم.
- يرسل التطبيق سياقاً محدوداً عن الاسم والشكل ومرحلة التطور والمهام والذكريات المسجلة.
- خيار «صوت Google» يحوّل الرد إلى كلام عربي عبر Gemini 3.8 Flash TTS. إذا تعذّر توليد الصوت، يحاول التطبيق استخدام صوت المتصفح.
- يمكنك لصق مفتاح API من الإعدادات؛ يرسله المتصفح إلى الخادم المحلي فقط، ويحفظه الخادم في .env بصلاحيات 600.
- لا يُحفظ المفتاح في localStorage ولا يظهر من جديد داخل الواجهة.
- واجهة إدخال المفتاح تقبل طلبات من loopback فقط، ولا تسمح لأجهزة الشبكة بإرسال مفتاح إلى الخادم المحلي.

المتطلبات
---------
- Python 3 (لا تحتاج إلى pip أو مكتبات إضافية).
- اتصال إنترنت.
- مفتاح Gemini API من Google AI Studio.

التهيئة على Linux Mint
----------------------
1) فك ضغط هذه الحزمة في مجلد عادي.
2) افتح Terminal داخل المجلد ونفّذ:
      chmod +x run-linux.sh
      ./run-linux.sh
3) في أول تشغيل سينشئ البرنامج ملف .env آلياً ويبدأ تشغيل الخادم.
4) افتح المتصفح على:
      http://127.0.0.1:8787
5) أنشئ مفتاح API من Google AI Studio:
      https://aistudio.google.com/app/apikey
6) من داخل التطبيق افتح «الإعدادات» ثم «الحديث الذكي · Google Gemini».
7) الصق المفتاح في حقل «مفتاح Google Gemini API» واضغط «حفظ المفتاح واختباره».
8) بعد نجاح الاتصال افتح «الحوار» واختر «التحدث مع النجم» أو «التحدث مع الكوكب».
لا تحتاج إلى فتح ملف .env أو لصق المفتاح في Terminal.
الصوت
----
فعّل خيار «صوت Google» داخل صفحة الحوار. يستخدم التطبيق Gemini TTS لصوت عربي مختلف لكل شخصية. قد يستهلك توليد الصوت طلب API إضافياً لكل إجابة؛ اترك الخيار مغلقاً لتقليل الاستخدام.

الأمان والخصوصية
----------------
- لا تضع المفتاح داخل index.html ولا ترسله في محادثة.
- لا تشارك ملف .env. الحزمة تتضمن .env.example فقط.
- الخادم يستمع افتراضياً على 127.0.0.1 فقط، أي على هذا الكمبيوتر.
- لا ترفع .env أو server.py مع مفتاح فعلي إلى Git أو استضافة عامة.
- لاستخدام الهاتف من خارج هذا الكمبيوتر أو لنشر PWA على الإنترنت، انشر الخادم خلف HTTPS مع تخزين GEMINI_API_KEY كمتغير سرّي في بيئة الاستضافة. لا تفتح منفذ الخادم على الإنترنت مباشرة.
- استخدام Gemini يخضع لحصص Google وشروطها وقد يتطلب إعداد فوترة بحسب حسابك والنموذج.

حل المشكلات
-----------
- «لم يُضبط GEMINI_API_KEY»: افتح الإعدادات والصق المفتاح مجدداً، وتأكد أن الخادم المحلي يعمل.
- 403 أو 401: تحقق من المفتاح والصلاحيات والمشروع في Google AI Studio.
- 429: وصلت إلى حد الطلبات أو الحصة؛ انتظر أو راجع لوحة الاستخدام.
- لا يفتح التطبيق عبر file://؛ شغّله عبر run-linux.sh ثم افتح localhost أعلاه.
- إذا كنت قد ثبّت نسخة PWA القديمة، امسح بيانات الموقع أو أزل النسخة المثبتة ثم ثبّت النسخة الجديدة من مصدر HTTPS.

النسخة مبنية على MY SPACE v15 مع الاحتفاظ بمفتاح بيانات cosmos1، وإضافة سجلات حوار منفصلة في بيانات كل نجم.
